# Kernel for Qualcomm SM7225 / Samsung Galaxy Tab S7 FE 5G

Kernel source for the Snapdragon 750G (SM7225) based Samsung Galaxy Tab
S7 FE 5G (SM-T736B, `gts7xllite`).

Based on Samsung's open-source release (4.19 stock import) with selective
stable and security backports.
